# 🚀 Thrive Africa - Generative AI & Prompt Engineering Course

Welcome to the **Generative AI and Prompt Engineering for Everyone** course! This is a practical, non-code course designed to empower you with hands-on skills in AI automation and web application development.

## 📚 Course Overview

This course focuses on practical, real-world applications of Generative AI through:
- **Automation with No-Code Tools** (Zapier & Make)
- **Web Application Development** with AI assistance
- **Deployment on Modern Platforms** (Vercel)

## 🎯 What You'll Learn

By the end of this course, you will be able to:
- Master prompt engineering techniques for various AI tools
- Build automated workflows using Zapier and Make
- Create and deploy web applications without coding
- Deploy production-ready apps on Vercel
- Apply AI tools to solve real business problems
