### Task

**Prompt A (Vague):**
```

```

Provide 3 digital marketing strategies that:
- Target local customers within 5km
- Can be implemented within 2 weeks
- Focus on social media
Include specific steps for each strategy.
```

2. Compare the responses

## Exercise 4: Chain-of-Thought Prompting

### Task
Ask the AI to explain its reasoning step-by-step.

**Example Prompt:**
```

Walk me through your thinking process.

## Exercise 5: Iterative Refinement

### Task
Learn to refine prompts based on responses.

**Starting Prompt:**
```
Help me write a business plan
```

**Refinement 1:**
```
Help me write a one-page business plan for a mobile car wash service
```

**Refinement 2:**
```
Help me write a one-page business plan for a mobile car wash service including:
- Service description
- Target market
- Pricing strategy
- Marketing approach
- Start-up costs breakdown
Format it so I can present it to a potential investor.
```

**Your Task:**
1. Start with a vague prompt on a topic of your choice
2. Refine it 3 times, making it more specific each time
3. Compare the quality of responses
