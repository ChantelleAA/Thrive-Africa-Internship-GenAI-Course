# Module 4: Web App Resources

## 🔗 No-Code Platform Directory

### Landing Pages & Websites

#### **Carrd** - https://carrd.co
**Best for**: Simple one-page sites
- **Pros**: Super simple, affordable, fast
- **Cons**: Limited to one page (free), basic features
- **Pricing**: Free (3 sites), Pro $19/year
- **Learning curve**: ⭐ (easiest)

#### **Webflow** - https://webflow.com
**Best for**: Professional websites, complex designs
- **Pros**: Powerful, beautiful designs, CMS
- **Cons**: Steeper learning curve
- **Pricing**: Free (2 projects), $14+/month
- **Learning curve**: ⭐⭐⭐⭐

#### **Framer** - https://framer.com
**Best for**: Interactive, animated sites
- **Pros**: Great for portfolios, modern design
- **Cons**: Learning curve
- **Pricing**: Free (1 site), $5+/month
- **Learning curve**: ⭐⭐⭐

### Full Web Applications

#### **Bubble.io** - https://bubble.io
**Best for**: Complex web apps with logic
- **Pros**: Most powerful, database, workflows
- **Cons**: Complex, can be slow
- **Pricing**: Free (limited), $29+/month
- **Learning curve**: ⭐⭐⭐⭐⭐

#### **Glide** - https://glideapps.com
**Best for**: Apps from Google Sheets
- **Pros**: Quick setup, easy data management
- **Cons**: Limited customization
- **Pricing**: Free (limited), $25+/month
- **Learning curve**: ⭐⭐

#### **Softr** - https://softr.io
**Best for**: Apps from Airtable
- **Pros**: Fast to build, professional look
- **Cons**: Depends on Airtable
- **Pricing**: Free (limited), $29+/month
- **Learning curve**: ⭐⭐

#### **Adalo** - https://adalo.com
**Best for**: Mobile apps
- **Pros**: Native mobile apps, good UI
- **Cons**: Performance limitations
- **Pricing**: Free (limited), $45+/month
- **Learning curve**: ⭐⭐⭐

### Form Builders

#### **Typeform** - https://typeform.com
- Beautiful, conversational forms
- Free: 10 responses/month
- Paid: From $25/month

#### **Google Forms** - https://forms.google.com
- Free, unlimited responses
- Basic but functional
- Integrates with Google Sheets

#### **Tally** - https://tally.so
- Notion-like form builder
- Free: Unlimited forms
- Modern, clean interface

#### **JotForm** - https://jotform.com
- Powerful form builder
- Free: 5 forms, 100 responses
- Many templates

### Database & Backend

#### **Airtable** - https://airtable.com
- Spreadsheet-database hybrid
- Free: 1,200 records/base
- Great for no-code apps

#### **Notion** - https://notion.so
- All-in-one workspace
- Can be used as simple database
- Free for personal use

#### **Firebase** - https://firebase.google.com
- Google's backend platform
- Real-time database
- Free tier available

## 💡 Best Practices

### Design
1. **Mobile-first**: Design for mobile, scale up
2. **Consistency**: Use design system/brand guide
3. **White space**: Don't overcrowd
4. **Hierarchy**: Clear visual hierarchy
5. **Accessibility**: Consider all users

### Content
1. **Clear messaging**: Say what you do clearly
2. **Scannable**: Use headings, bullets, short paragraphs
3. **CTAs**: Clear calls-to-action
4. **Social proof**: Testimonials, numbers
5. **Benefits over features**: Focus on user value

### Performance
1. **Optimize images**: Compress before upload
2. **Minimize resources**: Only load what's needed
3. **Test speed**: Use PageSpeed Insights
4. **Mobile testing**: Test on real devices
5. **Browser testing**: Test in different browsers

### User Experience
1. **Clear navigation**: Easy to find things
2. **Fast loading**: Under 3 seconds
3. **Forms**: Keep short, clear labels
4. **Error messages**: Helpful, friendly
5. **Confirmation**: Acknowledge actions

## 🐛 Common Issues & Solutions

### Issue: Site loads slowly
**Solutions:**
- Compress images
- Remove unnecessary elements
- Use lazy loading
- Check platform status

### Issue: Mobile layout broken
**Solutions:**
- Test in responsive mode
- Adjust breakpoints
- Simplify mobile layout
- Hide unnecessary elements

### Issue: Forms not submitting
**Solutions:**
- Check required fields
- Verify integrations
- Test error messages
- Check spam folders

### Issue: Can't connect to service
**Solutions:**
- Reauthorize connection
- Check API keys
- Verify permissions
- Test with dummy data
