# AI Prompt Templates

Ready-to-use prompt templates for various tasks. Just fill in the [bracketed] sections.

---

## Content Creation Templates

### 1. Blog Post Outline
```
Create a comprehensive blog post outline about [topic].

Target audience: [describe your audience]
Goal: [what should readers learn or do]
Tone: [professional/casual/technical/friendly]

Include:
- Attention-grabbing headline
- Introduction hook
- 5-7 main sections with subsections
- Key takeaways
- Call-to-action
- SEO keywords suggestions
```

### 2. Social Media Post
```
Create [number] social media posts about [topic] for [platform].

Audience: [describe your followers]
Goal: [engagement/clicks/shares/awareness]
Brand voice: [describe your brand personality]

Each post should:
- Be optimized for [platform] (character limit, hashtags, etc.)
- Include emoji where appropriate
- Have a clear call-to-action
- Include 3-5 relevant hashtags
```

### 3. Email Campaign
```
Write an email for [purpose] targeting [audience].

Context: [background information]
Main message: [key point to communicate]
Desired action: [what should recipients do]

Include:
- Compelling subject line (A/B test options)
- Personalized greeting
- Engaging opening paragraph
- Clear value proposition
- Strong call-to-action
- P.S. line
```

### 4. Product Description
```
Write a compelling product description for [product name].

Product details:
- Category: [type of product]
- Key features: [list main features]
- Benefits: [how it helps users]
- Target customer: [who would buy this]
- Price point: [premium/mid-range/budget]

Make it:
- Benefit-focused, not just feature-focused
- Scannable with bullet points
- SEO-friendly
- Emotionally engaging
- Include a clear call-to-action
```

## Business & Planning Templates

### 5. Business Idea Validation
```
Help me validate this business idea: [describe your idea]

Analyze:
1. Target market and size
2. Competition landscape
3. Unique value proposition
4. Revenue potential
5. Key challenges and risks
6. Resources needed to start
7. Success probability (1-10 with reasoning)

Provide:
- Honest assessment
- Specific concerns to address
- Suggestions for improvement
- Next steps to validate
```

### 6. Marketing Strategy
```
Create a marketing strategy for [product/service/business].

Current situation:
- Budget: [amount]
- Timeline: [timeframe]
- Target market: [describe]
- Current channels: [list what you're using]
- Goal: [specific measurable goal]

Provide:
- 3-5 marketing channel recommendations
- Budget allocation per channel
- Expected ROI for each
- Implementation timeline
- Key metrics to track
- Quick wins to start with
```

### 7. Problem-Solving Framework
```
I'm facing this challenge: [describe problem]

Context:
- Current situation: [details]
- Constraints: [limitations - budget, time, resources]
- Stakeholders: [who's affected]
- Desired outcome: [what success looks like]

Please:
1. Rephrase the problem for clarity
2. Identify root causes
3. Generate 5 potential solutions
4. Evaluate pros/cons of each
5. Recommend best approach
6. Outline implementation steps
7. Identify potential obstacles
```

### 8. Competitive Analysis
```
Analyze my competition for [product/service/business].

My offering:
- What I provide: [describe]
- Target market: [describe]
- Unique aspects: [what makes you different]

Main competitors:
1. [Competitor 1 name/website]
2. [Competitor 2 name/website]
3. [Competitor 3 name/website]

For each competitor, analyze:
- Strengths and weaknesses
- Pricing strategy
- Target audience
- Marketing approach
- Unique features

Then provide:
- Market gaps and opportunities
- Differentiation strategies
- Competitive advantages to emphasize
```

## How to Use These Templates

1. **Copy the template** you need
2. **Fill in** the [bracketed] information
3. **Paste into** your AI tool (ChatGPT, Claude, etc.)
4. **Review and refine** the output
5. **Iterate** if needed with follow-up prompts

## Tips for Better Results

- **Be specific**: More detail = better output
- **Provide context**: Help AI understand your situation
- **Set constraints**: Budget, time, resources, etc.
- **Specify format**: How you want the output structured
- **Ask for examples**: Request concrete examples
- **Iterate**: Refine based on initial output
- **Combine templates**: Mix and match for complex needs

## Customization Ideas

- Save your frequently used templates
- Create variations for different contexts
- Build a personal prompt library
- Share successful prompts with team
- Document what works best for you

---

**Remember**: These are starting points. Customize them to match your voice, needs, and specific situations!
