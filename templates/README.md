# Course Templates

This folder contains ready-to-use templates for various projects throughout the course.

## 📁 Template Categories

### 1. Prompt Templates
- Content creation prompts
- Problem-solving prompts
- Learning prompts
- Business planning prompts

### 2. Zapier Workflow Templates
- Email automation
- Form to spreadsheet
- Social media posting
- Lead notifications

### 3. Make Scenario Templates
- Multi-step workflows
- Data processing
- API integrations
- Report generation

### 4. Web App Templates
- Landing page
- Portfolio site
- Contact form
- Simple web app

### 5. Vercel Configuration Templates
- vercel.json configurations
- Deployment settings
- Environment variable templates

## 🚀 How to Use These Templates

1. **Copy the template** you need
2. **Customize** with your specific information
3. **Test** before deploying
4. **Deploy** to your platform
5. **Iterate** based on results

## 📝 Template List

See individual files in this folder for:
- `prompt-templates.md` - AI prompt templates

- `web-app-templates/` - Web application starters

- Start with simpler templates
- Customize to match your needs
